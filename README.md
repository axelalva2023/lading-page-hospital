
# 🏥 Landing Page Hospital

Página web desarrollada con **HTML, CSS y JavaScript**, conectada a una base de datos **MongoDB**.

### 🛠️ Tecnologías
- HTML, CSS y JavaScript
- Node.js y Express
- MongoDB
- SweetAlert para confirmar el envío del formulario de contacto

### 🚀 Deploy
- **Frontend:** Vercel
- **Backend:** Render, para gestionar el formulario de contacto y las imágenes.
